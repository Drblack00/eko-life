# Èkó Life — Accessibility Static Audit (M6)

Static (code/CSS) audit of the built client, 2026-10-09. No live screen-reader
or device testing was possible — see `docs/KNOWN_LIMITATIONS.md`.
Ratios were computed with the WCAG relative-luminance formula against the
palette in `web/src/styles/tokens.css`.

## 1. Touch targets ≥ 44px — ⚠️ PASS with 2 exceptions

- Base rule in `styles/base.css`: `button, [role="button"], input, select { min-height: 44px }`.
- Components verified: `.eko-btn` 44px (52px large), `.eko-tabs__btn` 60px,
  `.eko-hud__avatar` 44×44, `.eko-me__avatar` 64×64, Sheet/Dialog close 44px,
  checkboxes wrapped in 44px label rows.
- **FAIL ×2 (below 44px):**
  - `views/Auth.css` — `.eko-input__toggle` (password show/hide): `min-height: 40px`.
  - `views/Admin.css` — `.eko-admin__rowbtn` (roster row buttons): `min-height: 40px`
    (comment in CSS acknowledges the deviation).
- Note: `base.css` resets `a { min-height: 0 }` — inline text links are exempt;
  acceptable under WCAG 2.5.8 (24px floor), but any icon-only link added later
  must be re-checked.

## 2. `prefers-reduced-motion` — ✅ PASS

- Global kill-switch in `styles/tokens.css`: under `prefers-reduced-motion: reduce`,
  all animations/transitions are reduced to 0.01ms.
- `game/CityMap.tsx:85` — Three.js idle animation loop consults
  `matchMedia("(prefers-reduced-motion: reduce)")`.
- `views/Landing.tsx:35` — news ticker marquee renders a static list for
  reduced-motion users.

## 3. Safe-area `env()` usage — ✅ PASS

- `styles/tokens.css` defines `--sat/--sab/--sal/--sar` from
  `env(safe-area-inset-*, 0px)`; `body` in `base.css` pads all four sides.
- `--sab` (or siblings) consumed in 9 CSS files: Sheet, Toast, Landing, Auth,
  ComingSoon, CreateCharacter, Game, Admin — bottom tab bar and sheets clear
  the iPhone home indicator.
- `Admin.css` also uses `env(safe-area-inset-bottom)` directly.

## 4. Form labels on all inputs — ❌ FAIL (11 unlabeled inputs)

22 inputs/selects scanned (`<input>`/`<select>`/`<textarea>` in views).
Labeled via wrapping `<label>` (Auth's `Field` component), `<label htmlFor>`
(HomeTab bank amounts) or `aria-label(ledby)`: **11 pass**.
Unlabeled (no `<label>`, no `aria-label`, no `aria-labelledby`):

| File | Line | Input |
|---|---|---|
| `views/CreateCharacter.tsx` | 189 | character name (only an `<h2>` nearby — not associated) |
| `views/Admin.tsx` | 172 | admin broadcast text |
| `views/Admin.tsx` | 196 | player search |
| `views/chat/RoomsView.tsx` | 193 | room message input |
| `views/chat/RoomsView.tsx` | 290 | new room name |
| `views/chat/RoomsView.tsx` | 297 | new room topic |
| `views/chat/DmsView.tsx` | 107 | DM message input |
| `views/chat/DmsView.tsx` | 183 | new conversation username |
| `views/chat/FriendsView.tsx` | 68 | add-friend username |
| `views/chat/ChatTab.tsx` | 94 | city chat message input |
| `views/election/ElectionSheet.tsx` | 113 | governor broadcast text |

Recommended fix: one-line `aria-label` per input (message inputs) or wrapping
`<label>` (name/username/search fields). No visual change needed.

## 5. Color contrast (text vs background, AA ≥ 4.5:1) — ❌ FAIL (5 pairs)

### PASS
| Pair | Ratio |
|---|---|
| `--text` on `--bg` (day / night) | 16.49 / 16.17 |
| `--text-muted` on `--bg` (day / night) | 7.10 / 9.28 |
| `--text(-muted)` on `--surface` (night) | 13.81 / 7.93 |
| `--text-muted` on `--surface-2` (day) | 6.62 |
| `--primary-strong` link color on surface (day / night) | 5.93 / 12.98 |
| accent button text (dark on `--accent`, day / night) | 8.22 / 10.57 |
| white on `--danger` button (day) | 4.83 |
| active tab text on surface (night) | 5.37 |

### FAIL
| Pair | Ratio | Where |
|---|---|---|
| `--primary` (#0284c7) link text on white (day) | 4.10 | `a { color: var(--primary) }` |
| `--primary` link text on `--bg` (day) | 3.83 | same |
| white on `--primary` primary button (day) | 4.10 | `.eko-btn--primary` — the main CTA |
| white on `--primary` primary button (night) | 2.77 | same (night `--primary` is lighter #0ea5e9) |
| `--success` (#16a34a) on surface (day) | 3.30 | `.eko-leaders__money`, `.eko-profile__online` |
| `--danger` (#dc2626) on `--surface` (night) | 3.08 | error text in dark mode |

Recommended fixes (design decision needed — not applied in M6):
- Day: use `--primary-strong` (#0369a1, 5.93:1) for link text and the primary
  button background instead of `--primary`.
- Night: darken the primary button background (e.g. lagoon-700 #0369a1, or keep
  #0ea5e9 with dark text) so white text reaches 4.5:1.
- `--success` text on day surfaces: use `--palm-700` (#15803d) for text,
  or bold ≥18pt only.
- Night error text: use a lighter red for text on dark surfaces.

## 6. `:focus-visible` styles — ✅ PASS

`styles/base.css` defines a global `:focus-visible` (3px `var(--ring)` outline,
2px offset, radius). All buttons/links/inputs inherit it; no component
suppresses outlines without replacement.
